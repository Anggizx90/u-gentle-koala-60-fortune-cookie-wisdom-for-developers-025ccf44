Entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) bounty on make.fun.

`main.ts` (Node 22) writes one original fortune-cookie line for a software
developer — at most 120 characters, a single line — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> The legacy code you curse was once someone's proudest Friday, and yours will be too.

Run it with:

```sh
node main.ts
```
